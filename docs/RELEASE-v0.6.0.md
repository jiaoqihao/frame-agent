# Frame Agent v0.6.0

浏览器中的内容采集、AI 解释与生图，加入更容易使用的本地服务启动方式、可编辑风格记忆，以及图片提示词 skill。

## 更新

- Windows 双击「启动 Frame.cmd」启动服务；首次自动准备依赖与插件，已有服务直接复用，显示端口冲突与启动失败原因。
- 项目记忆支持角色/产品特征、文字风格和排除项；可清空、撤销最近保存，保留 10 次变更并检查窗口间编辑冲突。已有任务仍保留原记忆快照。
- 图片路线新增结构化提示词流程：主体、构图、光照、准确文字、参考用途、变化与保留项；编号与实际参考图片一致，异常最多修复一次。
- 参考 OpenAI 官方 imagegen skill 和图像提示词指南，约束无根据的装饰与旧风格干扰。记录最终提交的提示词，不增加图片请求次数。

## 下载与使用

- **frame-starter-0.6.0.zip**：完整源码、已构建插件和本地服务启动入口。安装 Node.js 24+，解压后双击「启动 Frame.cmd」，然后在 Chrome / Edge 扩展管理页加载 `dist`。首次安装依赖需要联网。
- **frame-extension-0.6.0.zip**：仅插件；已有本地服务的用户可单独更新。

从旧版升级需要关闭旧服务、更新服务文件并重启，在浏览器扩展页重新加载插件。保留原 `.data` 文件夹即可保留模型配置与项目数据。不要把启动包解压成另一个独立项目后期待它自动读取旧目录的数据。

## 验证与边界

52 项自动化测试通过，真实 MV3 扩展回归覆盖项目记忆保存/刷新/清空取消/撤销、文字草稿、AI 解释与追问、项目隔离和窄屏布局。已实测服务启动、健康状态与重复启动。

2026-10-30 使用已配置的 DeepSeek `deepseek-flash`，对自然人像、中文/价格海报、项目角色延续进行提示词评估：3 例结构通过，画面文字符合预期；人工检查配色覆盖和角色特征。图片调用次数为 0，没有接入或测试第三方 `gpt-image-2` 中转站，也没有宣称最终图片质量已完成 A/B 验证。

图片路线通常增加一次语言模型调用，异常修复最多再增加一次。SVG 路线无此额外调用。详见 [提示词调研](image-prompt-research.md)。
