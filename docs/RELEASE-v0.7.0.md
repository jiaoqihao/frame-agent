# Frame Agent v0.7.0 · 先理解，审核后绘图

网页原文经常是段落、概念或资料，不适合直接作为绘图要求。现在所有入口先生成可审核的绘图说明，用户确认后才进入 SVG 或图片模型。

- 右键入口改为「Frame · 理解并生图」；文字草稿点「整理内容」，截图预览点「理解截图」。
- 新增内容理解 skill：解释原意，整理主体、关系与标签，列出改写内容和待核实项。
- 审核卡片可编辑，支持查看原始文字/图片、放弃、确认生成；刷新保留审核草稿。
- 新增四步进度。审核任务持久化，重复确认不会重复绘图，结果保留原始内容和实际批准的说明。
- README 加入完整的 Mermaid 工作流图，详细说明见 [工作流文档](workflow.md)。

下载 `frame-starter-0.7.0.zip` 可获得完整源码、本地服务和插件；已有新版服务可单独下载 `frame-extension-0.7.0.zip`。更新后需要重启本地服务，并在浏览器扩展管理页重新加载插件。

截图理解需要支持视觉输入的语言模型。演示模式只验证流程。此次不接入或测试第三方图片中转站。

验证：56 项自动化测试通过；浏览器回归覆盖文字审核、审核草稿刷新恢复、真实截图裁剪后的理解/审核/生成、右键入口、SVG 与图片路线、原图编辑和项目隔离。使用 DeepSeek 对 RAG 说明段落实测原意解释与绘图说明改写，仅调用语言模型，没有调用图片中转站。
